## Current status

> ⚠️ **The current documentation is a work in progress.**

The current version of the wiki is a **raw import of the existing Confluence pages**. As a result, it should **not be considered a final or fully usable version of the documentation yet**.

The original documentation is available [here](https://diamondlightsource.atlassian.net/wiki/spaces/DIAGTECHWEB/pages/851992/MBF+Documentation).

In particular, the import is currently missing the images, LaTeX expressions and other formatting elements from the original pages.

The imported content is therefore primarily intended as a **starting point for the migration from Confluence to GitLab Wiki**.
